# Choose your surface

LensWord isn't one app — it's a shared backend behind five different ways to
use it. This table is generated from the same evidence-based product
registry used by [docs/internal/repo-audit.md](https://github.com/conectlens/lensword/blob/development/docs/internal/repo-audit.md),
so it can't drift from the audit that backs it.

<SurfaceChooser />

## Which one do I want?

- **Reviewing vocabulary day to day, in a browser** → [Web Application](/install/web-app)
- **Running LensWord for yourself or a team you're hosting for** → [Self-Hosting & Deployment](/install/self-hosting)
- **A native app on your machine, not a browser tab** → [Desktop Application](/install/desktop-app) — unreleased, build from source today
- **Capturing words while reading elsewhere on the web** → [Browser Extension](/install/browser-extension) — developer-mode install only
- **Giving Claude, Codex, Cursor, or another MCP client access to your vocabulary** → [MCP Server & Local CLI](/install/mcp-local-cli)
- **Previewing or importing local developer context, offline, without touching the server** → [MCP Server & Local CLI](/install/mcp-local-cli) (the `import-context` CLI command)
- **Local, opt-in AI mnemonic suggestions** → [Local AI / Ollama](/install/local-ai-ollama)

None of these surfaces has a tagged release yet — see [Trust & verification](/reference/verification) for exactly what has and hasn't been confirmed for each one.
