# Legacy changelog

The full, unedited content of the repository's root `CHANGELOG.md`,
preserved here rather than deleted. Entries in it were written before the
[product-aware changelog system](/reference/trust/release-process)
existed and describe changes to the repository as a whole rather than to
one specific, versioned product — reclassifying them into
[per-product changelogs](/reference/changelog/) after the fact would mean
guessing which product a given historical entry was really "for," which
this documentation doesn't do. Where a historical change is unambiguous
enough to classify honestly, it gets a real
[changelog fragment](https://github.com/conectlens/lensword/tree/development/.changes)
and appears in the relevant product's page instead; everything else stays
here, in full, as the historical record it always was.
