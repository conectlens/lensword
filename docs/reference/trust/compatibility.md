# Compatibility matrix

No LensWord product has a tagged release yet, so no compatibility range has ever been declared or tested end to end. This page reports that plainly rather than inventing a plausible-looking matrix — every cell below is genuinely `Not declared`, not a placeholder waiting to be filled with guesses.

| Product | Requires server/API version | Status |
|---|---|---|
| Web Application | Not declared | Not tested |
| Desktop Application | Not declared | Not tested |
| Browser Extension | Not declared | Not tested |
| MCP Server | Not declared | Not tested |
| Local CLI | Not declared | Not tested |

Once a product declares a `compatibility.requires.server_api` constraint in a changelog fragment (see `.changes/README.md`), this page will report it here instead of `Not declared`.
