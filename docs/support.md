# Sponsorship & support

LensWord is built and maintained in the open. If it's useful to you or your
team, sponsoring keeps development moving.

## What sponsorship funds

Real, ongoing costs — not a wishlist:

- **Maintenance** — triaging issues, keeping dependencies current, fixing what breaks.
- **Documentation** — the guides in this site, kept accurate against the actual code rather than aspirational.
- **Cross-platform desktop verification** — real macOS, Windows, and Linux hardware/CI time to close the verification gaps recorded in [Desktop Application](/install/desktop-app) (this documentation pass could only verify Windows; macOS and Linux need separate hardware).
- **Release signing and notarization** — a macOS Developer ID and Windows code-signing certificate, so installers stop showing Gatekeeper/SmartScreen warnings. Not funded today — every current build is unsigned.
- **Hosting** — infrastructure for anything beyond what contributors run locally.
- **Accessibility work** — no accessibility audit has been performed yet; sponsorship could fund one.

**What sponsorship does not buy:** roadmap priority, security guarantees, or private access. No such policy exists, and nothing here implies one does.

## Ways to sponsor

- **[GitHub Sponsors](https://github.com/sponsors/conectlens)** — individual or organizational.
- **[Patreon](https://patreon.com/ofcskn)** — individual.
- **Organizational sponsorship or partnership discussions** — email **[lensword@conectlens.com](mailto:lensword@conectlens.com)** directly; this isn't a self-service flow.

## Getting help — where to go

| If you have... | Go to... |
|---|---|
| A bug or feature request | [GitHub Issues](https://github.com/conectlens/lensword/issues) — this is where work is actually tracked |
| A security vulnerability | [SECURITY.md](https://github.com/conectlens/lensword/blob/development/SECURITY.md) — **not** a public issue, and not the sponsorship email above |
| A sponsorship or partnership question | [lensword@conectlens.com](mailto:lensword@conectlens.com) |
| A general product question | [lensword@conectlens.com](mailto:lensword@conectlens.com), or open a [GitHub Issue](https://github.com/conectlens/lensword/issues) if it's something others would benefit from seeing answered |
| Code or documentation to contribute | [Contributing](/contributing) |

No response-time guarantee exists for any of these channels.
